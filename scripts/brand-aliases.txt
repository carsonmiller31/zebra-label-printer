# Brands people still say on the phone that RxNorm no longer carries.
#
# Everything in public/paper/drugs.js comes from RxNorm's Current Prescribable
# Content — which is a list of what can be dispensed *now*. An office that has
# been calling in "Coumadin" for twenty years does not stop because the brand
# was retired, so these names are kept searchable by hand.
#
# This file is judgement, not data: it is about what people say, not about
# what a drug is. Nothing here changes a strength, a form or a dose — it only
# adds another word that finds an existing entry.
#
#   Brand = Generic name exactly as it appears in drug-names.txt
#
